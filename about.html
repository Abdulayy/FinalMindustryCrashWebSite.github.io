About this project

Mindustry atlas is a fan site about Mindustry, a factory and tower defense game where you mine resources, move them on conveyors and defend your core from waves.

The site has a browsable database of the game's content, a look at the campaign sectors, and more reference material in progress.

How it is built

  • Plain HTML, CSS and JavaScript. No frameworks and no build step.
  • Works on desktop and on phones, with a collapsing menu on small screens.
  • Hosted on GitHub Pages.
